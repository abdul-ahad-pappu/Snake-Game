# 🐍 Snake Game (Java)

This is a simple and fun **Snake Game** built using **Java Swing**. The game supports borderless movement (wrap-around), live scoring, high score tracking with player names, pause/resume, and replay functionality.

---

## 🎮 Features

- 🚀 Classic snake mechanics
- 🧱 Borderless gameplay – snake wraps around edges
- 📈 Score tracking
- 🏆 High score with player name memory (for current session)
- ⏸️ Pause and resume (press `P`)
- 🔁 Replay after Game Over
- ❌ Exit option on game end

---
